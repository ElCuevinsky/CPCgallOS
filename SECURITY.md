# Seguridad

Reporta vulnerabilidades de manera privada al responsable del club CPC Gallos.
No publiques credenciales ni formas de evadir el modo competencia en un issue
público.

El prototipo 0.1.0 no se considera endurecido para una competencia oficial. En
particular, la whitelist actual es una política del navegador y no reemplaza un
proxy o firewall de egreso administrado por la universidad.
