# Seguridad

Reporta vulnerabilidades de manera privada al responsable del club CPC Gallos.
No publiques credenciales ni formas de evadir el modo competencia en un issue
público.

El prototipo no se considera endurecido para una competencia oficial. En esta
revisión Chromium no aplica una whitelist de sitios; conserva el bloqueo de
instalación de extensiones no aprobadas. Eso no reemplaza un proxy o firewall
de egreso administrado por la universidad si se requiere control de dominios.
