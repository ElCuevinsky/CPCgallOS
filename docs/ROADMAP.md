# Roadmap

## 0.1 — prototipo

- Construcción reproducible desde Xubuntu 26.04 LTS Minimal.
- Dos modos de arranque en RAM.
- Toolchain C++/Java/Python, dos IDEs, Chromium y branding.
- Política inicial de paquetes, extensiones y navegación.

## 0.2 — endurecimiento

- Proxy/firewall de egreso por dominios.
- Persistencia cifrada.
- Pruebas automatizadas de la ISO en QEMU.
- Validación continua en GitHub Actions.
- Verificación de Secure Boot y RTX 50.
- Perfil AppArmor específico para herramientas autorizadas.

## 1.0 — competencia

- Imagen firmada, checksums publicados y proceso de liberación.
- Matriz completa de hardware universitario.
- Manual para encargados y procedimiento de recuperación.
- Versiones fijadas de compiladores según el reglamento del evento.
